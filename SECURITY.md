# Security Policy

## Dati da non versionare

Non inserire mai nel repository:

- password MQTT;
- credenziali TinyCam;
- token o API key;
- file `flows_cred.json`;
- certificati TLS e chiavi private;
- indirizzi pubblici o informazioni sensibili non necessarie.

Usare file locali esclusi da Git oppure variabili d'ambiente.
