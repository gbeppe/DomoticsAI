# ADR-002 — MQTT come protocollo principale

- Stato: Accettato
- Data: 2026-07-13

## Decisione

MQTT sarà il protocollo principale tra app, gateway e sistema domotico.

## Motivazioni

- aggiornamenti in tempo reale;
- comunicazione bidirezionale;
- supporto retain e QoS;
- integrazione naturale con l'impianto esistente.
