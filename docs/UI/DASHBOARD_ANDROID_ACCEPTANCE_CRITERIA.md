# Dashboard Android App — Acceptance Criteria Draft

## Realtime

- aggiornamento UI entro 1 secondo dal messaggio MQTT;
- indicazione dato stale;
- timestamp ultimo aggiornamento;
- riconnessione automatica;
- fallback locale/remoto.

## Configurazioni

- validazione client;
- validazione Gateway;
- stato `pending`;
- conferma valore applicato;
- timeout visibile;
- audit log.

## Grafici

- selezione intervallo;
- zoom;
- tooltip;
- unità coerenti;
- confronto serie;
- export futuro.

## Layout

- card riposizionabili;
- ordine persistente;
- visibilità configurabile;
- reset layout;
- supporto telefono e tablet.

## Sicurezza

- password non mostrate in chiaro;
- credenziali salvate in storage sicuro;
- conferma per azioni critiche;
- log dei comandi.
