# Requisiti Android

## Connessioni MQTT

Configurazione modificabile:

- host locale predefinito: `192.168.1.20`;
- host remoto Tailscale;
- porta;
- username;
- password;
- modalità Auto / Solo locale / Solo remoto.

La modalità Auto seleziona l'endpoint realmente raggiungibile, non soltanto in base al tipo di rete.

## TinyCam

Configurazione:

- indirizzo locale;
- indirizzo remoto;
- porta HTTP predefinita `8083`;
- selezione automatica dell'endpoint;
- visualizzazione live e fullscreen.

## Interfaccia

- Material Design 3;
- schede spostabili;
- dial energia;
- barra SOC Powerwall;
- grafici interattivi;
- tab per dati e configurazione;
- log MQTT RX/TX e connessioni;
- tema chiaro/scuro.
