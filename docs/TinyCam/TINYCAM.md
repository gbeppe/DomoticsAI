# Integrazione TinyCam

## Parametri

- protocollo: HTTP;
- porta predefinita: 8083;
- endpoint locale configurabile;
- endpoint remoto Tailscale configurabile.

## Da rilevare

- URL esatto della pagina o dello stream per ogni camera;
- autenticazione;
- formato stream;
- disponibilità snapshot;
- eventuali comandi PTZ.
