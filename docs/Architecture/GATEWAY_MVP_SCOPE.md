# Gateway MVP Scope

## Obiettivo MVP

Il primo Gateway deve supportare soltanto:

- disponibilità;
- energia;
- clima;
- VMC;
- log;
- comandi configurazione clima;
- modalità simulazione.

## Fuori scope iniziale

- luci;
- piscina;
- impianti termici completi;
- AI generativa;
- regole automatiche create dall'utente;
- notifiche push;
- PTZ avanzato.

## Criteri di completamento

Il Gateway MVP è completo quando:

- pubblica stato energia normalizzato;
- pubblica stato clima normalizzato;
- pubblica stato VMC normalizzato;
- riceve e valida configurazioni clima;
- produce ack e stato confermato;
- mantiene availability;
- registra RX/TX/errori;
- funziona in modalità simulazione;
- non dipende da Link node della produzione.
